# Comparação gRPC x RESTful (ASR 12)

As tecnologias gRPC e RESTful são amplamente utilizadas para implementação de aplicações e sistemas distribuídos, notadamente considerando o paradigma de Web Services.

Nos dois repositórios abaixo, encontram-se duas implementações alternativas de uma aplicação distribuída, a primeira utilizando RESTful e a segunda utilizando gRPC. Utilize-as para comparar as duas tecnologias do ponto de vista do modelo de programação empregado em cada caso e de aspectos como eficiência, modularidade, manutenibilidade, abertura, transparência de distribuição etc.

- Exemplo de serviço Web implementado com RESTful (`RESTful-WS-Example-main/`)
- Mesmo exemplo com gRPC (`gRPC-WS-Example-main/`)

Em seguida, teça uma comparação mais ampla, considerando a adequação destas duas tecnologias de uma forma mais ampla, por exemplo, considerando seu uso para a implementação de APIs a serem utilizadas por aplicações de usuário final (frontend) e para a implementação de APIs para interação entre serviços (backend). Em geral, que fatores devem ser considerados ao optar por uma ou outra tecnologia?
